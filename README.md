# 轻打卡（Vibelex Attendance）

一款极简、克制的移动端个人出勤打卡 PWA 应用。单手点一下按钮即可记录时间，自动推算应下班时间、净工时、单双休与存档假扣减，并自动生成月历与月度统计。

在线体验：**https://clock.jianfalab.com**

## 核心特性

1. **单手极速打卡**：拇指热区放置「上班 / 下班 / 休息」三个大圆角按钮，点击即记当前时间，支持 5 秒内一键撤销防误触。
2. **自动算账与时间尺**：
   - 支持 **弹性打卡**（`上班时间 + 标准净工时 + 午休` 自动推导应下班时间）与 **固定班制**（自动判定迟到）。
   - 首页内置「今日班次时间尺」，实时展示工作进度与加班延伸。
3. **单双休与存档假自动推断**：
   - 支持自由切换 **单休 / 双休**、**灵活每周配额 / 固定休息日**。
   - 自动区分「正常休息（不扣假）」「动用存档假（-1 天）」「半天假（-0.5 天）」与「法定节假日（不扣假不占配额）」。
   - 支持休息日出勤攒假、平日累计加班满 1 个标准工作日自动折算存档假。
4. **月历与工时分布图**：自动生成每日净工时柱状图（含标准工时基准线）、智能月历网格及休假判定明细，点击任意日期可补卡或微调。
5. **纯本地存储 & 离线秒开 PWA**：数据全部保存在手机浏览器 `localStorage`，不上传服务器；支持 JSON 备份导出/导入、离线 Service Worker 缓存秒开及手机桌面快捷方式安装。

## 本地开发

```bash
npm install
npm run dev -- --host
```

## 构建与部署

```bash
# 构建生产包
npm run build

# 部署到 Cloudflare Workers / Pages
npm run deploy
```
